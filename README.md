# 🎬 Movie Explorer

A modern, responsive movie search app built with **React + OMDB API** featuring search, filters, pagination, and a watchlist saved in LocalStorage.

## 🔗 Live Demo

👉 **[https://kaleidoscopic-tarsier-d190b4.netlify.app/](https://kaleidoscopic-tarsier-d190b4.netlify.app/)**

## 📂 GitHub Repository

👉 **[https://github.com/nainikapounikar/movieExplorer](https://github.com/nainikapounikar/movieExplorer)**

---

## ⭐ Features

* 🔍 Search movies, series, and episodes
* 🎚️ Filters: Type (Movie/Series), Year
* 📄 Pagination
* ⭐ Watchlist System (Add/Remove movies)
* 💾 Watchlist stored in **LocalStorage**
* 📱 Fully responsive UI (Mobile + Desktop)
* 🎨 Sticky header + Modern dark theme
* 🏠 Hamburger menu on mobile

---

## 🛠️ Tech Stack

* **React.js (Vite)**
* **OMDB API**
* **Bootstrap 5 + Custom CSS**
* **React Router DOM**
* **Netlify** for Deployment
